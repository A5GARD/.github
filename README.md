# A5GARD

Building developer tools inspired by Norse mythology.

## Projects

- **[BIFROST](https://github.com/A5GARD/BIFROST)** - Platform-agnostic CLI for scaffolding projects with community templates.
- **[MIDGARDR](https://github.com/A5GARD/MIDGARDR)** - UI components library, comprising of 2500+ components, tools and other features that would have been made into their own npm library / project if were built any where else.
- **[MIDGARDR-CLI](https://github.com/A5GARD/MIDGARDR-CLI)** - UI components library CLI. Once command install of the library and its components, tailwind, postcss and all the required configs.
- **[THOR](https://github.com/A5GARD/THOR)** - A custom tailwind alternative with zero dependencies.
- **[BIFROST](https://github.com/A5GARD/BIFROST)** - Platform-agnostic project creator with extensible template system inspired by Remix Stacks.
- **[BIFROST-PLUGIN](https://github.com/A5GARD/BIFROST-PLUGIN)** - Plugin installer / wizard for bifrost projects.
- **[BALDR](https://github.com/A5GARD/BALDR)** - React icons library

## Philosophy

Create tools that bridge developers to their next project, as Bifrost bridges realms in Norse mythology.

Platform-agnostic. Community-driven. Developer-focused. Providing a UX unlike any other.
